# 智算平台静态前端

企业级智算平台静态前端原型。项目不依赖后端，业务流、状态变化、日志和审计由前端状态模拟完成。

## 技术栈

- `React 19`
- `Vite 8`
- `TypeScript`
- `Tailwind CSS v4`
- `lucide-react`

## 运行方式

```bash
npm install
npm run dev -- --port 5173
```

默认访问地址：

`http://localhost:5173/#/`

## 当前模块

- 平台总览
- 算力规格
- 模型加密
- 敏感词策略
- 远程开发
- 模型微调
- 应用空间
- 云原生应用
- 分级发布

## 当前行为

- 页面切换后会自动回到顶部
- 所有动作均会更新页面内可见状态，部分动作会写入审计日志

## 关键文件

- `src/App.tsx`：页面结构、业务模块、状态脚本
- `src/styles.css`：界面样式和响应式布局
- `SESSION_CONTEXT.md`：当前项目上下文和接续说明

## 注意事项

- 不执行真实加密、真实 VS Code 拉起、真实 Kubernetes 部署或真实外部调用
- 当前仍是无后端静态前端，不是生产可用系统
